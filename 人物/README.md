## 共用写作原则

1. 三极拥有极端特化的能力，但常规军队、工程师、节点部队和后勤都对战局产生可见影响。
2. 每个人的优点都应带出代价：凌烬急于救人、洛弦善于计算、岳沉渊愿意承伤，既推动胜利，也造成错误。
3. 第三卷洛弦隐瞒风险的后果不会因一句道歉消失；第四卷岳沉渊的损伤不会在下一卷消失；第六卷末三极带伤进入第七卷。
4. 同一事件在不同人物眼中可以有不同评价，客观事实应一致。例如第三卷留守部队确实遭受重创，洛弦确实掌握撤离希望极低的推演。
5. 第一篇解决远征军入侵，保留星核来源与「种子」成熟后果。角色不得在终战前无根据地知道完整真相。

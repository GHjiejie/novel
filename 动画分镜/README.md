# 断星纪动画分镜

本目录按已有小说正文编写二维动漫改编稿，供分段视频生成、配音与剪辑使用。每章分镜保留原故事的选择与结果，并把心理描写转换成可见动作、声音或有限的记忆镜头。

## 第一卷天降帝星

| 章节 | 动画分镜 | 视觉配套 | 镜头清单 |
| --- | --- | --- | --- |
| 001 街边修剑的人 | [完整动画分镜稿](第一卷-天降帝星/001-街边修剑的人-动画分镜稿.md) | [人物道具与连续性](第一卷-天降帝星/001-视觉与连续性.md) | [镜头生成清单 JSON](第一卷-天降帝星/001-镜头生成清单.json) |

第001章分为8场、100个镜头，剪辑目标总长10分39秒。镜头清单包含完整的画面提示词、动作、对白、声音和时间安排；JSON为通用制作清单，使用时需要按具体平台输入，不能作为未适配的厂商API请求。

实际生成时先准备本镜人物与场景的参考图，逐镜生成并核对外貌和道具状态，最后处理配音、界面文字、字幕与声音。现有凌烬动漫图可用于人物参考，辅助人物和场景的待补图见视觉配套。分镜稿本身不包含已生成的视频或分镜图片。

故事依据保留在[小说正文目录](../正文/README.md)和[七卷细纲目录](../章节细纲/README.md)。

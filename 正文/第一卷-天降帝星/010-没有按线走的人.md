# 第010章 没有按线走的人

指挥车的屏幕上，一辆医院转运车驶进了没有开放的路段。

洛弦立即放大定位，发现跟在它后面的人更多。十几名居民扶着一面受损的围墙向前移动，还有人推着装衣物的车。原路线上的指示灯没有熄，他们却已经拐过了标记。

她接入路口广播：“前方出口未确认，请停在掩体后，等待改道。”

车辆停了一下。居民仍在向前走。

后面落下一阵炮火，墙后的烟迅速压上来。洛弦听见广播中有人咳嗽，随后有个声音抢过了扩音器。

“这里是通道值守。原出口被压住了，他们没地方等。”

值守把随身镜头抬高，洛弦看见箭头所指的下层通道仍有一盏灯，但灯下堆着两副临时担架。刚才一处水管受损，通道积水没过台阶，电动升降台已经退出。年轻人可以踩着旁侧窄沿进去，担架却要横过栏杆才下得去。

人群里一位家属反复拿着转院凭单，要求照单子上的入口去。他带来的病人不能淋水，也不想挤进临时避难处。值守已解释了好几遍，老人仍然说那个入口前面有人等他们，换地方别人找不到。

洛弦叫通联员向接收医院核对病床，自己把新的入口编号发到凭单登记端。对方终端屏碎了，读不出来，值守便拿走凭单，用笔把旧入口划掉，在背面写新的。

老人抓住纸不肯松，问是不是谁都能这样改。

洛弦接通现场扬声器，说自己是这条路线的调度者，接收医院已确认改道。她没有催他相信，先让医院值班员报出病人的转运编号。数字一一对上，老人才低头看那张被涂改的纸，随人群往新方向走。

但后面的人已经看见医院车转弯。有人拎着全部家当跟过去，原本互不认识的几家开始催促前车，觉得医院总会比临时出口可靠。

洛弦要求值守把车与步行者分开，在侧墙下圈出两块等待区。一个推行李车的人不愿离开，怕自己一走，物品就会被清路的人扔掉。他的车上捆着一台小型缝补机，断掉的电线绕在把手上。

“带得动就推去那边，门能过。”洛弦说。

值守试了入口的宽度，拆掉一截可以卸下的临时栏杆，终于把行李车也送进去。几名躲在后面的人这才开始移动。洛弦撤掉一处已经不再需要的限制，将那一点功率让给路口，指挥车里另外两条待答呼叫又闪了几次。

她调出上一份现场确认。不到一轮命令之前，那处出口还可以使用。屏幕里的绿色与眼前的烟撞在一起，她指尖顿了一瞬，随即拉开备用道路。

医院转运车停在一处窄弯，车侧有一条被碎片划开的白痕。车里的人要求先放车辆，因为后排病人已经用了很久的移动设备。路口值守则希望居民先走，车辆一进去，弯道就只剩下一边。

“车上能不能换到备用电池？”洛弦问。

“能换一组，只剩一组。”

“先换。人员从右侧过，车稍后跟。不要把担架拆下来，他们还要固定。”

她把两处临时停点发给值守，要求附近节点组暂缓穿过路口。东边的界钉安装因此落后了一截，图上一个空心圆始终没有变实。洛弦看着那枚圆，手指在桌沿敲了一下。

医院车后门开启。有人钻进去换电池，一名穿白衣的医护站在车尾举着手，替后方居民挡住车辆随时会启动的误解。人群终于在值守引导下，从预定的那一侧经过。

洛弦将新通道暂时纳入两枚界钉之间。织界从剑柄处传来细微的凉意，她逐一剔除正常通行的目标，只限制附近威胁向路口移动的角度。一个低空探测物从烟中探出来，被拖慢了片刻，守军将它打成一团碎火。

“出口通了。”值守报告。

她没有松手，等医院车也离开，才把那处限制解除。

这条临时路线保住了。她在记录栏里补上供能消耗，正要通知节点组继续行动，宋芮的声音从另一个频道进来。

“预定位置落不了钉。地面塌了，接口也烧了。”

指挥车外的一台发动机正在轰鸣，洛弦关紧车窗，把对方影像拉到主屏。画面里，一处地面检修槽被炸开，固定座倾斜在坑边，几根缆线冒着黑烟。宋芮戴着防护面罩，抱钉箱的手一直没松。

洛弦先确认她没有受伤，随后报出另一个坐标。

“向内退，靠左边立柱。不要用烧过的接口。”

“那边挨着居民刚走的路。”

“我会调整覆盖。你确认立柱是完整的。”

宋芮走近，画面晃了几下。她敲了敲柱面，清掉底部的碎砖，拍回三处可用位置。

她原本和另一名操作员一起运送界钉，那人此刻伏在坑边，想拉回还没烧断的一段线。宋芮把箱子先压在墙角，蹲过去扣住同伴的背带。坑里有电光闪了一下，她立刻叫他别碰金属外壳。

“上一段还通着，得先断！”

洛弦调出接口状态。记录显示那一段已经退出，她下意识让他们先拍清断点。宋芮镜头刚伸过去，地面上就跳起细小的白火，余下的缆线猛地抽动，打在操作员手套上。

宋芮没有再等，把人的胳膊拖回墙后。手套外层烧出一个洞，幸而没伤到里面。她转头对着镜头说，不能只看灯，地面有一条邻接线路还在送电。

洛弦重新核验，发现退出记录来自旧编号。她立刻叫工程组在分配柜端隔离，等对方给出第二次确认，再让操作员试取。

坑边那一段能留下，烧损的接头却不能用。宋芮把坏头拆掉，选择离裸线更远的位置放箱。那里比洛弦要求的墙角偏了一点，也使同伴可以安全蹲下处理护罩。

“钉还没装，箱子先在这里。”她说。

洛弦想将箱的位置移回方便布线的一侧，看到那只仍冒细烟的手套，又停住了。她保留箱子的临时位置，要求实际落钉仍按新坐标确认。宋芮把箱盖打开，重新检查固定翼，取下一片在奔跑中翘起来的薄铁屑。

洛弦在那个墙角旁补上临时箱位，又把宋芮拍来的裸线位置发给运输组。车里一直积着的待确认事项，少了一项，又多了两个需要通知的人。

洛弦在三个位置间来回比对。最靠外的可以补上工业通道，却会把供能拉得更长；靠内的安全，但要让已有节点多承担一段。她选定其中一个，报出安装角度，又要求宋芮把固定座旋过半圈。

“接口方向和原图不同，线不够。”宋芮说。

“用箱里的延长头。”

“备用接头留在车上了。”

洛弦想起临时指挥所里，自己曾经为让她跑得更快，留下了一部分配件。她没有责怪操作员，叫另一组从指挥车取件，又将落点转给工程队确认。

同一时间，岳沉渊的过热报告到达。

居民通道已并入分配站，地面共用回路温度持续上升。洛弦停住正在输入的坐标，给许知微发去请求，询问能否从另一支路补足。

“能挪一部分，但界钉的接入会更慢。”许知微回答，“陆衡在申请降载。那个备用锚点必须切过去。”

洛弦接通岳沉渊：“什么时候缩回？”

耳机里有嘈杂的脚步和水泵声。他的声音仍然平稳：“这批人过去。现在还能守。”

“我暂缓一组补能。不要再扩。”

“收到。”

她将他的回答写入预测，重新排列三处节点的顺序。延长头尚未送到，宋芮那一组继续等待；医院车已经通过的路线不再需要同样精度，她把那里的计算负担让给工业通道，再将能源分配站的边界压成一个更简单的形状。

旁边的记录员把一张打印条递给她，手指停在两个相近的坐标上：“运输组收到过前一版，刚才还在问是不是继续送到坑边。”

洛弦划去旧坐标，亲自补发更正，要求对方复述。

运输组把立柱的位置报了一遍，她才确认。那辆载着器件的小车已绕过一次错误路口，送到时外壳上多了一处弹痕。宋芮抱着延长头，先向驾驶员点了点头，再退回掩体。洛弦看着画面，默默删掉了自己图上原先保留的最快到达时间。

织界逐渐变暖。

车内明明开着通风，她的后颈仍积起汗。每一次移开某处限制，她都要再核对那里的居民是否真的离开。已经完成的现场确认夹在新消息之间，有些很快又被后来的情况推翻。

“二号路口，请确认医院车已过。”

“过了，后面又来了人。”

“有多少？”

“我看不全，在转弯后面。”

洛弦把车载观察镜抬高，却只见到一片烟。她让路口值守派人确认，再将一个警戒标记留在原地。她必须继续处理下一个位置，否则宋芮连手里的界钉都装不下去。

延长头终于送到。操作员蹲下接线，绿色指示灯亮了一瞬，又因供能不足降成黄色。洛弦没有让它进入完整工作状态，先把它当成一枚低负载的边缘节点，随后让相邻界钉调整角度补偿。

有两支部队同时问新的通行方向。她分别回答，语速越来越慢，防止自己把其中一组的坐标送给另一组。一个地方军官在第三次等待后说，眼前的墙快要顶不住，必须自己找地方退。

“先别穿过前方射界。”她说，“沿右侧墙移动，到了转角报告。”

“那需要跨过你的节点线。”

她停下另一处精细控制，专门给他开了通道。

凌烬的报告便在这时进入。

“南侧岔路有撤离车队受困。前排车辆堵住，救援人手没到。”

洛弦将他的位置拉到地图中心。他仍在工业窄口内侧，靠近倒下的敌重装。背后的守军正在搬弹箱和修炮位，正面观察没有显示新的重装进入，却有几处无法确认的信号在烟里活动。

“不要离开拦截区。工兵和当地部队在调整。”

“他们现在走不动。”

“我正在确认路线。”

凌烬给了她一个画面。岔路上挤着车辆，最前面的车侧斜在一处残损路基旁，车门被后车挡住。有人站在后排，挥着一块浅色布。更远处，一道火线落在车队旁边，人群全都低了下去。

洛弦放大路面裂痕。车辆能不能退出，需要工兵看过才知道。凌烬所在的位置到车队并不很远，来回却不只是一条地图上的线，还包括打开堵点、安排车辆、确认所有人听见了同一道指示。

“你去，谁接重装？”她问。

“我可以赶在它们进来之前回来。”

“这里没有确认过的推进时间。”

她将最近的工兵队位置拉到前面。那队人背着起吊支撑和探测器，原本负责外环一处塌损门廊。洛弦向他们发去车队影像，对方看过前车角度，要求从内侧接近，不能直接穿过工业口。

最短路并非没有人，却会经过第三火力班正在整理的炮位。让工兵走那条线，既要停一段射击，还要把重装的推进时间赌进去。洛弦划掉那个选项，给出更长的支路，让救援车先到另一头等。

“先送两个人过去看地面，支撑架后送。”她说。

工兵队长报出已经动身。她将移动信号转给凌烬，想让他看见有人正在走向那支车队。

“这条路太绕。”他说。

“他们带的东西要从这边过。”

“我不用带支撑架。”

洛弦将前车下方放大：“你先过去，也要等支撑架。切开表面不一定能让车走。”

“能把人带出来。”

“那里面有多少不能走的人？”

没有立即回答。凌烬手里的画面再次摇晃，远处的呼喊还在催促。洛弦等他核对，另一个岗位又叫她，她只能将声音压低，先把该岗位所需的出口确认。

“你说等，”凌烬忽然问，“他们会知道还要等什么吗？”

她握着织界的手紧了一点。刚才转院的家属也问过相似的话，可让他们停在遮蔽里，与让他们独自留在车上，又有不同的时间。

她请疏散调度向车队播报工兵位置，要求讲清从哪一头来，不要只说正在处理。随即，她接到第三火力班的确认：炮架已更换一只底座，火力能恢复，但近场拦截仍只有凌烬。

她把这句话发给他，停下别处的对话，完整说了一次：“工兵已经出发。你要留在他们无法替代的位置，救援需要的东西会继续送。”

他的定位未动。她以为这次终于把两种时间接在了一起。

“最近的落点在后面。我看过。”

“它们可以换路。你刚才接触过的目标也没有全部信息。”

对方短暂沉默。洛弦仍能听见车队频道里的呼喊，声音从他那边传过来，与她刚才接到的请求混在一起。

她叫守军军官报可接替人数。答案是正在组织，但原来的侧翼小队被压住，还要重开一个通行口。工兵先行人员的信号也停了一次，一辆遗留在巷中的配送车堵住窄路，后续支撑架过不去。

洛弦接上那条线，让他们先从车旁挤过，另叫救援车绕到巷尾接物。队长确认两个人可以继续向岔路口走，却不能保证带得动完整器件。他的镜头里，一人蹲下卸车上的空箱，另一人扶住探测器，抬过墙边的破管。

她把新到达顺序发给车队调度。页面上不再是齐整的一支救援队，只剩前后拉开的几个实点。最前面的仍在走，后面的也没有放下手中的支撑架。凌烬要她回答的时间，却不会因此自动缩短。

屏幕另一边跳出警告。两枚相邻界钉同时受到射击，火力来自一个先前没有露面的方向。

洛弦抬眼，看见观察画面里有小型侦察设备沿厂房边缘移动。它们没有直冲工业窄口，而是贴着地面绕开最亮的节点。先前几次拖慢重装的银线，已经把部分位置暴露给了敌人。

她迅速改变一枚节点的控制方向，又给宋芮发去隐蔽要求。

“停止移动，留在立柱后。不要去取前面的线。”

宋芮确认收到。几乎同时，能源分配站要求再次降载。岳沉渊的边界在新一轮冲击中发黄，洛弦将部分输出向他让去，东面的节点图随之变薄。

她握住织界，试图逐一稳定那些变化。每个位置都还有办法，只差一道确认、一段线、一次及时的回报。只要她把顺序理清，图上那些互相挤压的条件就能再次衔接。

凌烬仍没有报出接受留位。

“接替尚未完成。”洛弦重新接入他的频道，“现在留在原位。”

地图中央的光点动了一下。

她先以为是定位受到干扰，随后看见第二次更新。那个光点沿着装卸台边缘转向南侧，离开了她刚刚重新分配过供能的区域。

凌烬的定位信号，正在走出原定拦截区。

# 断星纪小说正文

第一卷《天降帝星》已完成20章正文，从货运街修剑、交通会议和轨道救援展开，写到帝国入侵、首次协作失利、天京保卫战与三极建立。

人物关系通过实际经历推进：三人第一次试接未能完成断线交接，战场上的救援、扩界与集中调度让缺口扩大；复盘后，他们与守军、工程和医疗人员共同创造一次有限的突破。胜利之后，病床、遗物、居民安置和失败的合练继续承接战争代价。

# 第二卷《地球三灾》逐章详细细纲

**章节范围：**第021—040章，共20章。

**时间跨度：**天京保卫战结束后的约四个月。前半卷建立封锁下的补给与联合行动，后半卷围绕不断加密的侦察、敌方运输与一场诱导性的局部战役展开。

**进入本卷时：**十二座星井仍由人类控制，天京外围与部分轨道设施受损；三极获得正式单位编号，只有一次成功协同的经验；地球尚不知道帝国的长期补给方案，也未掌握其夺井用途。

**离开本卷时：**补给与城市联系被勉强维持，宁澈成为洛弦信任的节点军官，伊瑟处于受监管的有限技术合作阶段；三人的称号与公众期待形成，帝国掌握其主要战术限制，外缘中继门开始支持远征准备。三极赢得局部战役后，十二座星井同时报警。

## 逐章细纲

### 第021章 废墟上的补给表

**视角与场景：**韩策主视角，天京临时指挥部、受损的储能中转站。

**目标与阻力：**把首次胜利变成能够持续作战的体系；维修、救援与前线争抢同一批储能载体，各地区又不愿交出仅存运输力量。

**场景拆解：**

1. 韩策在庆功通知抵达前先看缺口表，发现外围医院与炮阵将在同一夜耗尽备用能源。他召集两方负责人逐项核验需求，把有常规电源替代的岗位从优先名单移出。
2. 凌烬请求连夜追击退走的登陆军，许知微让他查看照夜导流部件与运输船的维护记录：即便杀进敌后，返程也没有可靠供能。他接受先护送维修车队，仍把这视为耽误了反击。
3. 洛弦提出固定三极的行动程序，岳沉渊补上平民撤离条件。韩策要求每次任务同时列出常规部队、工程人员和退出时刻，拒绝用“三极能处理”填补空栏。
4. 中转站遭残余无人机袭扰，三人配合守军保住载体，却只能让半数抢修队当夜出发。其余队伍在废墟旁等到天亮，首次胜利的账单由此落到具体的人身上。

**人物推进与伏笔：**三极开始有程序上的合作，个人习惯尚未改变；有限储能和维修周期成为后续每次胜利的前提。

**章末钩子：**来自外海的补给船报告：预定降落港的导航灯全部熄灭。

### 第022章 雨夜里的界钉箱

**视角与场景：**宁澈主视角，运输港外围、断电仓街。

**目标与阻力：**在补给船抵达前恢复港区局部剑域；原定布点的建筑坍塌，节点箱必须穿过仍有敌军游荡的街区。

**场景拆解：**

1. 宁澈率新编节点部队报到，逐个复核箱号和备用线，而非先向洛弦展示队列。他发现图上的第六处节点没有承重墙，主动带她到现场确认，迫使原方案重画一个角。
2. 洛弦按新的街巷长度计算延迟，要求两个小组同时落位。宁澈把秒数拆成搬运、固定和校准三个口令，让第一次配合的操作员听懂自己何时该做什么。
3. 雨水损坏一组接口，敌方巡逻机又扫进仓街。宁澈没有丢下箱体逃走，而是用备用线绕过积水层，普通守军压住巡逻机，使节点在最后时刻接入。
4. 洛弦只控制靠近港口的短走廊，成功偏转一轮火力。宁澈亲眼看见每道命令都换来可用通路，认为严格执行她的计算，便能让队伍活着完成任务。

**人物推进与伏笔：**宁澈正式登场，有现场专业判断，却仍把最终安全寄托在洛弦掌握的全局；记录布点时间和撤退道路的习惯持续保留。

**章末钩子：**一辆敌方重装车停在剑域边缘，既不开火，也不进入已经亮起的通道。

### 第023章 黑剑切开停电区

**视角与场景：**凌烬主视角，港区防御场转换站与高架检修道。

**目标与阻力：**击杀负责破坏防御场的重装指挥单位；目标停在射程优势区，护盾结构陌生，接近路线暴露在交叉火力下。

**场景拆解：**

1. 转换站连续跳闸，凌烬从残余脉冲判断敌车在测试防御场响应，却无法直接确认主节点。他请求炮兵连续打击同一侧，让修复过程暴露各层护盾的替换顺序。
2. 敌车释放与动力结构相似的诱饵，凌烬第一次切入落空，装具储能迅速下降。他退回检修道，压住立刻再冲的冲动，听取工程员报告真实散热管的位置。
3. 宁澈的节点组把接近通道延迟三秒，守军用烟幕遮断侧向火力。凌烬沿炮击制造的凹陷近身，以折甲连续破坏一个连接段，迫使指挥单位把护盾转到错误方向。
4. 照夜切开控制舱，防御场随即恢复，补给船得到进港机会。凌烬拒绝拍摄斩杀特写，转身去追仍在破坏线路的敌军；他的行动速度成为战报最醒目的数字。

**人物推进与伏笔：**“断星”开始从天京斩舰的口耳相传变成正式战报里的称呼；凌烬把一次纠错后的成功理解成自己仍能赶上所有威胁。

**章末钩子：**缴获的控制终端里，除攻击记录外还有一张港区地下结构图。

### 第024章 三条街通向同一门

**视角与场景：**洛弦主视角，旧城三岔街、港口外环炮阵。

**目标与阻力：**把分散侵入的敌军引入交叉火力区；界钉数量有限，守军不敢放开街口，居民也仍在从侧巷撤离。

**场景拆解：**

1. 洛弦发现敌军在绕开转换站，准备沿三条街攻击起降场。她要求守军开放其中一条看似较弱的通道，地方军官担忧敌人会借此冲入民用避难点，拒绝立即执行。
2. 宁澈带人核对避难入口，把仍有平民的支路从计划中删去。洛弦重新布设短距离节点，牺牲一段控制范围，以换取清楚可见的人员分界，地方守军才同意配合。
3. 敌军先遣察觉迟滞，停步试探。炮兵必须忍住过早开火，等装甲纵队转入狭口；洛弦以万军回廊压缩几处转向空间，无法同时阻住另一条街的突围。
4. 交叉火力摧毁主纵队，常规步兵夺回节点缺口。敌方幸存者的通信中首次出现“像一张天罗”的描述，地球译员把这个词连同整场协同记录一并转交宣传部门。

**人物推进与伏笔：**洛弦得到“天罗”的初步称号，也感到只要计算足够细就能解决争议；宁澈看见她修改方案，更愿意把未知部分交给她判断。

**章末钩子：**敌军回收队放弃伤车，专门拖走了一具装有测量仪的残骸。

### 第025章 最后一艘船落地前

**视角与场景：**岳沉渊主视角，轨道运输港防护基座、起降场。

**目标与阻力：**支撑港口防护，让最后一批补给船落地；地面锚点受损，港区卸载设施无法承受持续满负荷运行。

**场景拆解：**

1. 两艘运输船带着伤员进入下降段，敌舰隔着防御场反复压低高度。岳沉渊把归墟接入港口基座，先询问冷却能够维持多久，随后让维修队按最危险的连接处排序抢修。
2. 一处锚点烧毁，防区内出现短暂缺口。他用镇岳固定阵位，把穿透攻击导向仍可用的地下卸载槽，装甲内温度持续攀升，地面守军必须击退低空无人机才能保住维修人员。
3. 港务负责人主张中止最后一船的降落，岳沉渊要求确认空中返航能源。得知船上已无足够余量，他同意放弃外围货场，只守起降线与维修通道，使防护功率降到可承受范围。
4. 船体触地时主基座跳闸，岳沉渊以归潮清开冲入跑道的残骸，守军拖走伤员后才拆除回路。船员说最后那道灯始终没有坠下，“不坠”由此在港务频道传开。

**人物推进与伏笔：**岳沉渊能遵守一次必要收缩，却更难拒绝最后一艘船；锚点、冷却与人力接替共同支撑他的威名。

**章末钩子：**修甲时，他把仍在发抖的手藏到桌下，先问下一支船队何时来。

### 第026章 墙上的三个名字

**视角与场景：**凌烬主视角，临时安置区、联合防卫新闻室。

**目标与阻力：**用港口战果稳定公众信心，同时补足实际救援；宣传画把“断星、天罗、不坠”画成无所不能的三道防线。

**场景拆解：**

1. 凌烬到安置区送还一件从废墟带出的工具，发现墙上已出现三人的画像。居民拿着画像问何时夺回轨道城市，他没有答案，只能确认眼前供水车确实会按时抵达。
2. 新闻室计划播出连续胜利的剪辑，韩策要求保留伤亡与设施损失。负责宣传的人担心数字会压低士气，双方最终同意分开呈现战果和救援需求，却未能消除观众对英雄的全部投射。
3. 洛弦接受采访时强调节点部队的作用，画面却被截成“她掌控城市”的标题。宁澈认为这是简化的必要代价，还替她整理下一场部署，未意识到部队本身正被叙述隐去。
4. 岳沉渊被居民请求护送一支物资车队，答应在原任务后赶去。三人没有公开许诺全线必胜，却各自加了一项额外任务，修复和休息时间再次被挤占。

**人物推进与伏笔：**称号开始被大众固定下来，连续胜利强化三人的旧习；宣传有现实需要，也会让拒绝求援变得更难。

**章末钩子：**帝国译员把三张画像摆上赫因的战术桌，请他批准新的联合威胁档案。

### 第027章 三灾档案

**视角与场景：**赫因主视角，远征旗舰情报室、模拟战场。

**目标与阻力：**用已付出的损失找到三极的稳定限制；影像有缺段，不能把一次成功反击误认成完整能力上限。

**场景拆解：**

1. 情报官汇总登陆舰残片与港口记录，将三人分别编号。赫因要求删去“不可摧毁”的结论，让技术员逐帧标出凌烬何时停下来观察、洛弦的节点何时被运到、岳沉渊依赖哪些固定设施。
2. 模拟组尝试重装正面突击，结果反复被锁、守、斩切开。赫因改令同时破坏侧路和供能，模拟中的三极虽然仍能杀伤高阶单位，却无法守住全部区域。
3. 一名军官请求以大规模轰炸消除威胁，赫因指出地下结构与星井仍须保留。他批准假节点、链路干扰和远程消耗的小规模试验，以有限损失换来真正可用的边界数据。
4. 士兵私下把三个编号合称“地球三灾”，赫因不处罚这个称呼，却要求把敬畏写成可执行的规避程序。主力部队随后减少对天京投入，转去测试其他星井的响应。

**人物推进与伏笔：**反派会承认敌人战力并改变战术；三极成名的同一批影像，也是帝国准备多线攻势的教材。

**章末钩子：**旗舰航图上出现十二个地表标记，另一个运输标记远在太阳系外缘。

### 第028章 不经过天空的信

**视角与场景：**宁澈主视角，东亚地下通信干线、山区中继站。

**目标与阻力：**在民用网络受压制后恢复两座城市的可靠联系；旧线经过地质裂段，敌方小队已提前潜入修复路径。

**场景拆解：**

1. 宁澈护送通信工程队沿地下检修道前进，发现坏点并非单纯轰炸所致，几段接口被按相同方式拆走。他将异常报告给洛弦，同时保留实物，避免急于给帝国目的下结论。
2. 山区出口遭伏击，原定界钉不能隔着岩层控制敌人。宁澈先让守军清出一处可标定的坡面，再搬运节点箱；洛弦通过仍能接通的军用链路提供局部控制，掩护工程人员进入中继站。
3. 接线时有人建议优先恢复英雄战报，宁澈把伤员转运表和各地供能读数放到第一队列。他亲自带一份纸面命令穿过无信号区，让下一站知道电力切换的确切时刻。
4. 干线恢复后，联合防卫机构终于拿到不同星井遭试探的同类记录。洛弦赞许宁澈在现场删去不可用节点，却仍要求战术变化全部回报，由她批准后再纳入全图。

**人物推进与伏笔：**宁澈有能力承担独立判断，但将其视为替洛弦提供更准的数据；地下测量与通信拆件的关联尚属疑点。

**章末钩子：**一个偏远接收站请求帮助：那里俘获的运输车上仍有敌方伤员活着。

### 第029章 停在伤员前面的敌人

**视角与场景：**凌烬主视角，受袭维修车队、临时停火线。

**目标与阻力：**截住破坏供能线路的敌方维修分队，保全可审查的设备；对方把车辆停在伤员旁，正规护卫则准备毁掉记录撤离。

**场景拆解：**

1. 地球侦察兵确认运输车正在维护袭扰装置，凌烬不能因它带有伤员标记便放其离开。他让守军封住道路，先以广播给出放下武器、分离伤员和设备的具体要求。
2. 正规军护卫点燃数据舱，技术军官伊瑟却带人扑灭靠近治疗箱的火，并拒绝执行抛下重伤者的撤退命令。他没有向地球投诚，只以断断续续的翻译要求停止向医疗区射击。
3. 凌烬借护卫与维修车脱开的时刻突入控制位，切断武器供能，常规部队压住其他方向。伊瑟确认己方已经失去突围条件，交出个人武器，但把部下名单紧握在手中。
4. 医护人员逐一标记伤情，一份残余资料被从烧毁的舱体中抢出。凌烬没有逼伊瑟当场解释技术秘密，先把伤员送往受监管的医疗点；敌人也第一次以具体面孔进入人类后方。

**人物推进与伏笔：**伊瑟正式登场，行为以保住部下为中心；凌烬的克制使俘虏可活着被核验，不等于彼此已建立信任。

**章末钩子：**伊瑟听见治疗设备缺能的提示音，说自己知道一台缴获装置还能怎样启动。

### 第030章 一页资料换一张病床

**视角与场景：**伊瑟主视角，俘虏医疗点、隔离审查室。

**目标与阻力：**为部下争取可持续的治疗；地球急需情报，部分审查人员把他的技术价值与治疗优先次序混在一起。

**场景拆解：**

1. 伊瑟被问及同族部队驻地，拒绝回答，并要求先看伤员的编号与处理结果。韩策制止将必要医疗作为惩罚，说明重伤者按病情救治，但长期专用设备与转运仍须确认资源。
2. 伊瑟提出交换有限的能源设备维护页，以帮助省下治疗用的储能。他把可公开的接口说明和会暴露友军位置的通信表分开，只交出前者，地球审查员记录这条明确边界。
3. 许知微在隔离台上复验资料，发现其中一项切换顺序与缴获实物不合。伊瑟指出车辆曾换装，随后提供能被拆检证明的维修痕迹，双方第一次以事实纠正彼此的判断。
4. 新启动的治疗装置维持住一名伤员，伊瑟才在交换记录上签署确认。他仍拒绝回答帝国战略问题，也不承诺帮助地球作战；许知微把下一次询问限定在设备真正做过的事情。

**人物推进与伏笔：**合作从可核验的小范围交换开始，治疗具有自己的伦理与资源程序；伊瑟不是全知情报源，也没有立即倒戈。

**章末钩子：**许知微发现这台帝国装置的输入需求，可能由地球储能载体满足。

### 第031章 两种能源的同一负载

**视角与场景：**许知微主视角，地下测试室、俘虏医疗站。

**目标与阻力：**验证星核储能载体能否替代部分帝国能源制品；接口、稳定性与保护协议不同，贸然直连会烧坏唯一的可用设备。

**场景拆解：**

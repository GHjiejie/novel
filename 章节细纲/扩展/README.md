# 星核战争篇分卷情节支撑

七卷情节支撑把战役之外的生活、关系、专业分歧和社会后果接到逐章推进中。各章内容同时并入上一级的[七卷细纲](../README.md)，这里方便连续查看本卷支线。

| 卷次 | 情节支撑 | 贯穿的主要经历 |
| --- | --- | --- |
| 第一卷 | [天降帝星](01-第一卷-情节支撑.md) | 货运街日常、三名普通岗位人物、初次误解与协作、拒降后的公共信任 |
| 第二卷 | [地球三灾](02-第二卷-情节支撑.md) | 民间修造、节点队生活、宣传误用、俘虏合作边界、公开影像与侦察 |
| 第三卷 | [十二星井战争](03-第三卷-情节支撑.md) | 真实撤离准备、被隐瞒的接应、工程接防债务、难民身份和幸存者证词 |
| 第四卷 | [不坠之城](04-第四卷-情节支撑.md) | 公交征用与乘客去向、避难公平、工程旧账、伤员照护与未结责任 |
| 第五卷 | [天罗](05-第五卷-情节支撑.md) | 复健生活、工厂坏件与返工、失物和赔付、知情训练、数月远航 |
| 第六卷 | [断星](06-第六卷-情节支撑.md) | 民用征用、队员自主权、旅客与回收泊位、真实职业取证、敌方维护分歧 |
| 第七卷 | [星核战争](07-第七卷-情节支撑.md) | 卸载区居民、俘虏与工人、烧伤后的接班、调查证词、康复与有限外部关系 |

每条支线都要留下后续结果：一件物品没有归还、一个承诺未能兑现、一条路线因真实行动改变、一名幸存者拒绝被代替发言。卷末可以完成主要战役，生活与关系中的问题仍由活下来的人接着处理。

人物出场、伤势、星井归属和信息传播继续参照[连续性与伏笔表](../连续性与伏笔表.md)。

# 第三卷《十二星井战争》逐章详细细纲

**章节范围：**第041—060章，共20章。

**时间跨度：**十二井警报后的约两周。前三日部署与试探交错，随后一周形成局部围困和接连失守，最后数日处理撤离、伤员和九井网络的失衡。

**进入本卷时：**人类仍控制十二座星井，三极因上一场战役聚在天京附近，但运输与储能都有限；帝国已完成多线侦察和中继门部署的关键阶段，各处进攻均有真实威胁，主攻分配尚不清楚。

**离开本卷时：**莱茵、撒哈拉、极南三井失守，人类控制九井；凌烬的大量击杀未能扭转欧洲战局，最终护送撤离；洛弦隐瞒留守任务的真实风险，宁澈部队遭重创，幸存者拒绝再接受这种指令；岳沉渊守住南美井，却因扩大防区失去行动能力，被闻岚与守军救回。本卷仅造成暂时伤势和装备消耗，归墟仍完整，永久右臂与神经损伤留到第四卷。敌方获得三井空间测定基线，人类尚未明确其入口计划；能源分流把海岬城推入疏散危机。

## 逐章细纲

### 第041章 三张离港凭证

**视角与场景：**韩策主视角，全球联合指挥席、天京紧急转运场。

**目标与阻力：**在十二处真实攻击中完成防御调配；敌军兵力并不平均，通信延迟与不完整情报使任何集中增援都可能押错方向。

**场景拆解：**

1. 各井请求三极到场，韩策要求先报告登陆规模、供能余量与撤离能力。一些地区只见小队，却因输送站已被袭击同样无法忽视；他拒绝把低兵力自动等同于佯攻。
2. 欧洲已有大量重装与工兵降落，东亚主干线路正遭切割，南美的卸载设施连续受损。韩策据此将凌烬派往欧洲、洛弦留在东亚、岳沉渊送往南美，其他九井由地方守军和其余剑客负责。
3. 三人核对物资时发现同一套备用接口被重复申请。许知微拆分维修箱，提醒每个战区必须准备没有另外两人时的战术，转运部队为此临时多装一班工程人员。
4. 宁澈跟随洛弦回节点驻地，岳沉渊登船前先问南美居民撤路，凌烬握着欧洲路线图检查最短距离。三张离港凭证被签出，没有一张保证下一次还能同时返航。

**人物推进与伏笔：**联合单位首次真正拆分，地方军队承担完整战役；三人仍各自相信既有专长足以补上缺口。

**章末钩子：**凌烬的运输船尚未降落，莱茵战区便请求他直接转向正在失守的桥头。

### 第042章 莱茵桥头的第一道隙

**视角与场景：**凌烬主视角，欧洲莱茵井外缘、铁路桥头。

**目标与阻力：**击退威胁技术人员转运的敌方突击队；当地部队不了解凌烬的接近条件，原计划把他投在没有掩护的正面。

**场景拆解：**

1. 凌烬在运输舱里看见桥头影像，发现目标有与天京不同的护盾冗余。他要求地方炮兵先打掉侧翼观察器，指挥员提醒每发高功率炮弹都在消耗莱茵井防护所需的储能。
2. 他改用较低功率的连续压制制造接近窗口，随步兵从铁路检修槽进入桥下。敌军把一处动力节点做成诱饵，凌烬以实际交锋确认真结构，再用折甲迫使护盾切换。
3. 一名高阶单位被斩，桥头装甲失去指挥，地球守军及时夺回桥面。技术人员与伤员得以穿过，凌烬主动接下一项清剿任务，认为可以借短时间内连续斩杀打断整场登陆。
4. 地方指挥部上报漂亮战果，但铁路北端供能站同时遇袭，获救的车队无法继续开进井区。凌烬看见清空的桥头又开始堆积车辆，第一次听见“目标已灭，路线仍不通”。

**人物推进与伏笔：**个人突破确实救人，却需要后方运输接续；帝国以替换指挥和拆毁交通削弱战果的战略价值。

**章末钩子：**新的敌方指挥信号从相邻街区接替广播，像刚才的斩杀从未发生。

### 第043章 东亚主干线上的白点

**视角与场景：**宁澈主视角，东亚供能走廊、节点预置营地。

**目标与阻力：**布设能够保护主干线的局部网络；敌方干扰移动迅速，地图上的备用撤路又被满载平民车队占据。

**场景拆解：**

1. 宁澈把各组界钉标成白点，发现洛弦预设的西侧节点必须穿过已停电的高架区。他带操作员现场核查，建议改走更长的河堤，洛弦批准后要求所有时间误差准确回报。
2. 第一批节点被远程火力摧毁，宁澈回收还可用的导流部件，用普通工兵的临时掩体保护第二次落位。部队付出伤亡，网络才覆盖主干线附近几个关键口，无法包住整个东亚。
3. 宁澈询问撤退路线是否也要标进操作图，洛弦给出暂定的南口集合点，表示后续转运由她统一安排。他要求各组先熟悉入口，仍相信未给出的细节是她已经协调好的部分。
4. 当地炮兵利用短暂迟滞击退首轮攻击，主干线恢复稳定输电。宁澈让新操作员看这一刻的负载回升，告诉他们准确执行能保住很多城市，洛弦在另一块屏上继续接收恶化的运输报告。

**人物推进与伏笔：**信任通过真实成功继续加深；撤路被占用已成为已知事实，洛弦逐渐把不利信息留在自己的屏幕上。

**章末钩子：**南口的运力报告连续三次被调低，节点部队的任务图却没有更新。

### 第044章 南美井前的卸载沟

**视角与场景：**岳沉渊主视角，南美星井防护环、外围维修阵地。

**目标与阻力：**稳住井区防护，为当地守军修复卸载设施争取时间；帝国以分散袭击迫使防护回路不停改变重心。

**场景拆解：**

1. 岳沉渊抵达后没有立即承接全部火力，先跟工程队走过卸载沟，确认尚能工作的一段。当地防护剑客负责两侧，他把归墟接到中央锚点，暂时组成可持续的接续阵位。
2. 敌方炮击先压南面，再用低空载具突向北侧维修口。岳沉渊无法隔着整个井区护住北侧，必须由普通守军和另一名剑客击退载具，工程人员才赶在冷却耗尽前焊回线路。
3. 主卸载沟恢复，井区稳定输出，地方指挥员安排轮换。岳沉渊接受检查，却听见外围居民区因道路截断仍未撤完，要求把相关人数和距离加到自己的防护图上。
4. 侦察兵确认敌军在居民区附近设置观察器，扩大保护会增加一倍以上边缘接口。工程队明确说明当前系统只适合守井，他仍让人准备额外锚点，认为至少能再多护一条路。

**人物推进与伏笔：**本地军队并非等英雄出现才会作战；岳沉渊开始把有限防区外的人也视为必须亲自承担的责任。

**章末钩子：**一班撤离车因桥梁遭袭折返，停在防区边缘的住宅街口。

### 第045章 沙暴掩住的工兵车

**视角与场景：**撒哈拉战区地方守军主视角，沙漠防护站、星井维修公路。

**目标与阻力：**挡住北非的地面突破，保持井区补给；远程炮击把车队赶进狭窄维修路，帝国工兵正利用沙暴靠近输送设施。

**场景拆解：**

1. 守军在沙暴间隙击退一次明显的正面攻势，随后发现油料、冷却液和备用载体车队全部迟到。侦察组冒险沿公路巡查，找出敌人埋设的信号标桩，证明交通受袭是协调行动。
2. 地方剑客摧毁一个重装目标，却无法同时清除分散的工兵车。常规部队必须夺回两处路口，才能让维修车进入；一处被夺回后又遭远程覆盖，补给窗口只维持了半小时。
3. 联合指挥席收到请求，韩策不能立即把凌烬从欧洲调来，只提供一批储能和空中侦察。当地指挥员接受现实，重新安排撤离顺序，给技术资料与伤员预留同一批车位。
4. 地球后方截获一页帝国维护记录，许知微让伊瑟核验组件用途。他只确认那是测量设备，并明确自己不知道上级要测什么，不愿用猜测换取更宽的活动范围。

**人物推进与伏笔：**北非守军有自己的胜利和选择；三极无法填满全球缺口，伊瑟仍保持受监管的技术合作边界。

**章末钩子：**沙暴散去，远处工兵车已经在井区侧翼筑起一道新的运输坡道。

### 第046章 十七次斩杀后的断路

**视角与场景：**凌烬主视角，莱茵外围三处阵地、临时战果室。

**目标与阻力：**以连续斩杀阻止欧洲包围成形；帝国不断替换指挥单位，工兵与远程火力又不依赖某一个高阶目标。

**场景拆解：**

1. 凌烬在数日内往返多个阵地，凭地方侦察和炮兵创造的窗口击杀多名高阶单位。战果室挂出累计数字，前线士兵为他欢呼，他便把下一场攻击安排在原本用于休息的时段。
2. 一次斩杀后，敌军通信只停了短短片刻，新的控制节点接入。工兵继续铺设旁路、拆毁铁路，凌烬追回来的补给车又被堵在下一处断口，照夜却已需要更换导流件。
3. 地方参谋要求他选择保运输线还是追杀新的指挥单位。他选择先斩最近的目标，成功消灭威胁后回到公路，才发现维修车缺乏掩护而被迫撤回，井区的冷却余量继续下降。
4. 参谋没有否定斩杀价值，而是把敌军控制面积、己方伤亡和物资缺口并排展示。凌烬拒绝接受失守预判，要求给他一份更多、更快的突击清单，却无法回答车辆怎样穿过断路。

**人物推进与伏笔：**他的旧信念达到最强时，也与战略事实最为冲突；大量击杀真实有效，却未能恢复战区运转。

**章末钩子：**莱茵星井第一次因缺少冷却物资主动降低输出，外围防御场随之变薄。

### 第047章 多出来的一排锚点

**视角与场景：**岳沉渊主视角，南美井区外侧、住宅撤离路。

**目标与阻力：**在守住星井的同时保护被堵的居民车队；新防区超出原有卸载能力，敌方正利用扩展接口制造持续压力。

**场景拆解：**

1. 岳沉渊赶到住宅路，看见地方守军正在把车辆分批送往井区避难口。他认为等待期间仍会受袭，提出把承界扩到整条街，工程员指出新增锚点没有足够冷却容量。
2. 他让备用装具承担短时差额，许诺车队通过就收缩范围。最初几轮攻击被导入空沟，居民安全移动，守军因此相信扩展可行，开始把更多滞留者引向同一条路。
3. 帝国改变火力间隔，使新节点不能在两轮间散热。岳沉渊听见远处仍有人呼叫，再次延后收缩；井区中央锚点电流升高，当地防护剑客被迫接走本属于他的部分任务。
4. 地方指挥部提醒扩大保护正在削弱星井正面，他仍想靠归潮释放积累冲击补上差额。撤离组织人员紧急分开车流，但备用卸载槽已经亮起连续过温警告。

**人物推进与伏笔：**救人的成功把他推向更大的承诺；别人已经在接走他看不见的代价，后续救援将让这一点无法回避。

**章末钩子：**一处临时锚点脱落，住宅路与井区之间的防护连接开始反复闪断。

### 第048章 没有画出的返程

**视角与场景：**洛弦主视角，东亚战术推演室、节点部队待命区。

**目标与阻力：**保住即将被切断的主干能源线路；需要一支节点部队留守诱敌，已知道路与运力条件却使其几乎无法撤出。

**场景拆解：**

1. 洛弦完整读取南口报告：桥梁已断，接应运输队的剩余车位不足，敌火覆盖使备用通道几乎不可使用。她把这些条件带入推演，得到留守部队生还希望极低的结果，时间早于正式命令。
2. 她尝试换用远程节点，发现无法达到诱敌所需精度；若直接放弃，该段主干线将失去掩护。洛弦决定保线，却只在留给自己的附页写下实际风险，向调度席递交省略返程缺口的执行简报。
3. 宁澈询问部队怎样出来，她仍说：“按标定时刻退到南口，会有接应。”他据此分配装备，没有机会把真实条件告诉操作员；这句承诺不是未知事故前的合理判断，而是她知道不能保证仍作出的误导。
4. 留守组进入阵地，洛弦要求各节点等统一撤回口令。她确认诱敌路线有效，保存原始推演，认为由自己承担骂名便足以承担决定，却未把代价的选择权交给实际执行者。

**人物推进与伏笔：**错误明确落在知情权被剥夺；保住能源的必要性不能使虚假的接应承诺成立，时间戳与简报成为之后问责依据。

**章末钩子：**宁澈在出发记录上写下“南口接应已确认”，洛弦看到后没有纠正。

### 第049章 迟迟不来的撤回口令

**视角与场景：**宁澈主视角，东亚留守节点阵地、南口废弃换流站。

**目标与阻力：**维持诱敌网络并带部下抵达接应点；敌方攻击节点箱与退路，迟到的撤回指令仍按不足的运力条件执行。

**场景拆解：**

1. 宁澈率部维持几处关键节点，敌军被引入预设火力区，主干线获得修复窗口。他让伤员先移动到南口，自己带剩余操作员替换被击穿的界钉，相信统一撤回后运输队会接住他们。
2. 炮火切断一组连接，宁澈改用备用线保持诱敌条件，付出更高人员暴露。他请求提前撤出最受压的小组，洛弦要求等主干线隔离完成，未说明接应能力原本就不够。
3. 撤回口令终于到达，部队在南口只见断桥与无法穿越火力带的少量车辆。宁澈改带人员进入换流站，组织守军守住排水道口，救援请求被送往仍在现场的工程小组。
4. 多个节点失联，重伤员与器材堵住狭窄出口。宁澈让还能行动的人先走，自己拖着一名操作员留到最后；地方工兵从侧道进入，只来得及带出部分幸存者，留守部队遭到重创。

**人物推进与伏笔：**他的现场判断救下一小部分人，却不能补回被隐去的撤路；主干线稳定和部队失联同时出现在战报上。

**章末钩子：**宁澈被抬出时还在问接应车辆在哪，回答他的只有烧毁的南口地图。

### 第050章 写不回去的战果

**视角与场景：**凌烬主视角，欧洲前线指挥所、莱茵井外环。

**目标与阻力：**恢复井区与外界的最后运输联系；储能可供短时突击，却不足以同时修好铁路、保护车队和维持星井满功率防御。

**场景拆解：**

1. 凌烬请求携最精锐的部队反击敌方运输坡道，地方指挥员同意一次有限行动，条件是到时撤出。他们击毁重装与桥梁上的敌军火控，普通工兵却因冷却液不足无法继续修路。
2. 井区工程员展示负载曲线，说明并非星核能量枯竭，而是输出、输送与设备维护同时受限。凌烬问能否再减民用供电，得知医院、避难层和水泵已经处在最低负载。
3. 另一条撤离路线被敌军工兵封住，前线要求派凌烬再去斩一个目标。他第一次迟疑，因为每次转移都使上一条路线失去掩护；仍能作战的地方剑客提出接替突击，让他守住唯一转运口。
4. 地方指挥部开始为放弃莱茵井制定预案，明确设施保护与人口撤离不能同时保证。凌烬拒绝立即签认，要求最后侦察一次井口，战果数字却再也换不回已经失去的道路。

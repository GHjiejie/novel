# 断星纪星核战争篇章节细纲

本目录把[修订大纲](../断星纪·星核战争篇·修订大纲.md)展开为七卷、140章，每卷20章，供后续逐章写作使用。每章明确主视角、目标与阻力、三个以上可展开的场景、人物变化、伏笔和结尾承接。人物心理与能力边界同时参照[角色档案](../人物/README.md)。

七卷依次完成天京拒降、封锁拉锯、十二井争夺、海岬守城、撒哈拉反攻、超级星舰决战与阻止抽核。最后一卷包括本次远征结束后的问责、康复和种子悬念，第一篇获得完整战争结局。

## 细纲的使用方式

写作时先确认本章人物想完成什么、受到什么阻力，再依次展开场景中的动作、信息、选择与后果。章末钩子把刚发生的变化带入下一章；安置、补给、复健和调查也各自改变人物能做的事，不只承担战斗间的过渡。

采用第三人称有限视角。每章以标明的人物为观察中心；确需切换战场时，在清楚的场景分隔后交代新的观察者与地点。读者可通过帝国或外缘小队的独立场景获得额外信息，地球指挥部必须等实际收到记录后才能据此行动。

本细纲保留原大纲的核心事实。新增的小型行动、局部地点、任务过程、卷内时间安排与章名属于展开方案，正式写作时可以微调。尚未确定的种族、生理外观、血缘与爱情关系继续保持开放；角色图片中的视觉补充不自动成为新的历史事实。

## 全篇必须守住的条件

1. 剑客的突破依赖距离、有限储能、实际布设的节点与常规部队创造的条件；伤势与损坏随章推进。
2. 第三卷人类由十二井减至九井，第五卷夺回撒哈拉后持有十井，第七卷隔离敌方两井供能并在撤军后全部收回。
3. 洛弦第三卷隐瞒风险的责任持续存在。第五卷的合作建立在公开信息与现场权力上，战后调查继续进行。
4. 岳沉渊第四卷留下永久右臂与神经损伤，第五卷起使用重建装备和有限强度战术；洛弦第五卷的感知迟滞延续至终战。
5. 外缘突击队第五卷提前出发，第六卷先送出证据与实体样品，第七卷才破坏中继门的重型补给能力。
6. 终战前先完成地表反馈隔离与卸载，再斩断锁定环。抽核组件被毁、重型增援被切断、证据外流，共同迫使这次远征结束。
7. 帝国仍存在，赫因活着撤离。种子档案只说明当前数据符合旧判定规则，六个同类目标消失的原因与成熟后果留待下一篇。

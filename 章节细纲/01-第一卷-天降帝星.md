# 第一卷 天降帝星逐章细纲

本卷覆盖第001章至第020章。主线是三名尚无共同作战经验的剑客在天京首次遭遇帝国入侵，经历协作失败，再与守军和工程队共同保住星井。入侵前的日常、接触与首轮地面作战安排在约三天内，卷末留出数日处理伤亡和组建联合单位；这一时间安排属于本细纲的写作补充。

进入本卷时，十二座星井均由人类控制，三人没有「三极」的正式编制。「断星」「天罗」「不坠」尚未成为公众普遍使用的战场称号。离开本卷时，天京星井保住，外围城区与部分轨道设施受损；三极完成第一次有限协作，个人缺陷尚未解决，帝国转向持续围困。

### 第001章 街边修剑的人

**视角与场景：**凌烬，天京货运街的维修铺与轨道站外。

**目标与阻力：**他要在防卫设施巡检前换好「照夜」的导流部件。街区的运输故障使工作一再被打断，也让他无法把注意力仅放在剑上。

**场景拆解：**

1. 凌烬拆开朴素剑柄，拒绝店主推荐的装饰剑鞘，检查旧部件的磨损方向。维修铺使用星井供能，却仍要等零件和货运班次，借具体生活呈现能源丰富与设施有限同时存在。
2. 站外一辆运送维修器材的车辆卡住通道。他先看堵点与人群，再帮检修员打开旁侧出口；一次小事故让读者看到他的行动习惯，而非先听一段英雄履历。
3. 一个孩子追问剑能不能救下任何人。凌烬没有作保证，听完孩子的话，把修好的扶手交还检修员。他在短暂沉默中想到过去那几步没能赶到的距离，不明确当年死者的身份。
4. 巡检通知送达，他带着尚需复校的剑离开。街边广告仍宣传星核带来的繁荣，店主却发现一次普通结算请求迟迟没有收到轨道中继的确认。

**人物推进与伏笔：**建立凌烬修剑的日常、对通路的敏感和救援执念。结算延迟只是异常征兆，角色此时不能据此判断外星入侵。

**章末钩子：**天京的晴空中，一枚平日准时经过的通信节点没有出现在预定轨迹上。

### 第002章 地图上的空白

**视角与场景：**洛弦，城市防卫与交通联合会议。

**目标与阻力：**她要否决一份把道路通行能力算得过高的疏散方案。其他部门担心调整会影响生产，现场人员则认为她的精确图表遗漏了实际拥堵。

**场景拆解：**

1. 会议按既有模型推算全城撤离速度，洛弦指出其中一处备用路段与主干线共享供能，停电时两条路会同时失效。她要求工作人员说明真实设施条件，而非重复总体数字。
2. 交通值班员提出，居民不会完全按标记移动，医院与维修车也不能被当作同一种流量。洛弦修正了路线，却仍倾向由自己集中安排每个变化，表现专业与控制欲的共同来源。
3. 她检查随身界钉和「织界」的校准状态，要求运输组把实际落点写入记录。通过工具使用解释剑域依靠布设与供能，不把她画成能凭空控制城市的法师。
4. 会议被外层通信异常打断。她留下有线系统和地下通道的纸面备份，要求先确定信息来源；有人急着撤销日常工作，她坚持不能靠一条未经核实的警报让人群自行挤向出口。

**人物推进与伏笔：**洛弦关心生命，但习惯把现场意志视为需要被修正的变量。备用线路的共享故障将在第一轮战斗中成为真实代价。

**章末钩子：**她刚保存的城市地图上，几个本应独立工作的通信区域同时变灰。

### 第003章 扶住轨道

**视角与场景：**岳沉渊，高速轨道事故现场。

**目标与阻力：**他要让受损车厢中的乘客进入安全平台。车辆的承重与供能状态不断变化，救援者也需要接近才能完成转移。

**场景拆解：**

1. 列车因普通设施故障停在危险位置，事故不能在缺乏证据时直接归咎于帝国。岳沉渊先向机务人员询问承重与制动状态，再把「归墟」接入临时锚点，建立有限保护区。
2. 工程人员固定车体，消防和医疗组逐节疏散。岳沉渊导走平台接缝处的冲击，只处理系统最危险的缺口；车厢稳定来自多支队伍的工作，而非他一人托住整条轨道。
3. 指挥员提出更换锚点与短暂轮换，他听见车尾仍有人呼叫，决定再守一段。他把“不离开”当作最可靠的承诺，也让维修队不得不加快一个原本可以从容完成的交接。
4. 最后几名乘客被转出，他确认道路已通，才检查过热护具。普通救援的疲劳尚未消退，公共频道忽然中断，轨道调度要求所有人立即使用地面备份网络。

**人物推进与伏笔：**建立他的温和、工程意识与拒绝交接的倾向。此处只是一次日常过载，不造成第四卷才出现的永久损伤。

**章末钩子：**救援广播重新亮起，传出的却不是城市调度员的声音。

### 第004章 被夺走的频道

**视角与场景：**韩策，联合防卫指挥室；短切天京街区。

**目标与阻力：**他要在通信节点受袭后维持可信指挥。敌人压制民用网络，各地既收到相似警报，又无法确定哪些资料被篡改。

**场景拆解：**

1. 外层节点失联、近地雷达异常和民用频道被占的报告依次到达。韩策要求按来源核验，切换有线与部分军用链路，明确还能够联系哪些战区，避免写成彻底断网后的全球即时协同。
2. 有地方部队准备对未知舰体直接开火，也有人请求先撤走轨道人员。韩策分别处理防护、识别与撤离任务，把有限确认过的事实送回各地，保留地方应急判断的空间。
3. 近地防御设施遭到精确打击，损伤报告说明人类有抵抗能力，却不足以靠一次齐射结束接触。镜头切到天京，公众看到频道恢复，以为故障已经解决，随后陌生徽记覆盖所有公开屏幕。
4. 韩策保留播送原始记录，安排可核验的接触方式，不让技术人员在恐慌中覆盖数据。他第一次意识到，这场战争的第一处阵地是人们相信哪一条信息。

**人物推进与伏笔：**建立韩策整合普通部队与政治授权的职责。存档程序为后续截获文件、调查命令与对外传递证据提供基础。

**章末钩子：**公开频道宣布来者所属：帝星庭。

### 第005章 没有保证的自治

**视角与场景：**韩策为主，赫因通过有限接触与通牒出现。

**目标与阻力：**地球需要判断是否存在可以核验的和平条件。帝国愿意保留地方政府，却要求先解除防御、交出星井、人员与技术。

**场景拆解：**

1. 赫因平静宣告条件，不靠咆哮和侮辱建立威胁。他把接管描述为恢复秩序，准确指出地球的航行与工业尚无法在星际环境中独立自保。
2. 接触代表要求自治的监督办法、人员安全保障与接管后的能源安排。对方给出形式上的承诺，却拒绝任何可核验约束，双方立场由具体条款而非空泛口号冲突。
3. 联合机构内部出现分歧：继续谈判也许能争取时间，解除防御却可能使下一轮谈判失去全部筹码。韩策提交已证实的轨道损失与敌方要求，不替政治代表宣布所有问题都有唯一答案。
4. 地球拒绝按通牒解除防御，同时保留接触渠道。韩策把决定转为各战区可执行的防护和疏散命令；仍主张谈判的人被保留在制度内，为后续内部分歧留下现实基础。

**人物推进与伏笔：**赫因的控制理念通过谈判方式体现；韩策承受拒绝通牒后的责任。此时人类尚不掌握能源垄断的完整技术机制。

**章末钩子：**帝国的第一批登陆载具改变航向，目标是天京。

### 第006章 不能炸毁的井

**视角与场景：**许知微，天京星井地下维护层。

**目标与阻力：**她要在防御负荷上升时保持供能，判断敌人为什么绕开某些容易摧毁的设施。能源潜力巨大，线路与输出仍有上限。

**场景拆解：**

1. 许知微把正在抢用同一段供能的城市护盾、交通设施和医疗需求分别列出，拒绝“星核无限就全部打开”的要求。工程队必须进行真实的分流、冷却和线路切换。
2. 她向守军说明星井是地下异常节点的耦合设施，正常钻探抵达不了星核。防守井口与控制系统，是为了保住人类已经建立的稳定联系，不是守一条直通地核的矿道。
3. 敌方打击摧毁外层设施，却避开关键地下区。许知微把这一选择记为待查线索，不能直接猜到空间入口或种子；工程测绘终端出现异常访问，资料的用途开始变得可疑。
4. 防卫会议要求给出设施能支撑多久。她明确区分理论上限与现场已损伤的状态，提出先保住能够支持撤离和防护的支路，将暂缓恢复的城区逐一告知调度员。

**人物推进与伏笔：**许知微既提供技术希望，也公开技术边界。地下测绘被关注，将与卷末被敌回收队带走的资料互相印证。

**章末钩子：**维修层收到命令：天京防线需要三名剑客同时接入。

### 第007章 三个不相容的位置

**视角与场景：**洛弦，星井外环临时指挥所。

**目标与阻力：**三人必须在第一次共同作战前明确分工。彼此的名声能证明能力，不能代替配合经验，现有情报也无法支持完美方案。

**场景拆解：**

1. 凌烬带着街区巡检的路线资料到场，岳沉渊刚完成救援，洛弦已经列出初步部署。三人知道对方姓名，却对行动方式没有信任基础，第一次交谈就落在能否改变计划上。
2. 韩策让守军说明阵地、炮位与撤离口的位置，再安排凌烬拦截重装突破单位、洛弦维持局部节点、岳沉渊保护供能与掩护区。剑客负责具体缺口，普通部队仍负责守住真实地域。
3. 凌烬追问防区外的求救如何处理，洛弦坚持变化必须先报告，岳沉渊表示可以多承接一些火力。这三种听来负责的回答已经暴露将要相互放大的问题。
4. 许知微交代每人的储能、冷却与接口限制。计划得到签发，但无人充分演练通信中断时的交接；守军只来得及把关键通道和撤退点告诉他们。

**人物推进与伏笔：**建立第一次协作的明确初始条件，后续失败才能归因于具体选择。这里没有正式「三极」命名，也没有立即形成共同价值观。

**章末钩子：**前沿报告重装单位落地，三人第一次进入同一张作战图。

### 第008章 登陆艇的死角

**视角与场景：**凌烬，天京外围工业防线。

**目标与阻力：**他要阻止敌方破盾单位接近守军阵地。陌生护盾让单次试探失效，只有守军的压制与连续观测才能暴露结构变化。

**场景拆解：**

1. 地面部队将敌重装单位引进预先标定的火力区，凌烬借掩护接近。第一次出剑只切下一块外层装甲，反作用与耗能提醒他不能把陌生设备当成已知目标。
2. 洛弦用已落位的界钉限制敌方转向，守军继续攻击同一节点。凌烬记录护盾补偿的间隔，利用「折甲」形成缺口，再用「灰闪」完成短距离突破。
3. 一个敌指挥节点被摧毁，地方阵地获得喘息。普通士兵负责确认残余威胁、抢修炮位和拖走伤员，让这一战的成功成为多个岗位共同完成的结果。
4. 凌烬把短暂胜利理解为“只要能赶到就能处理”，主动询问还有哪些求救。远处的敌人没有继续投入同类单点目标，而在通道外展开工兵与侧翼火力。

**人物推进与伏笔：**「断隙」依赖试探、信息与接近条件的规则第一次实战落实。局部胜利增强了凌烬的错误信念，也让敌人开始学习他的行动习惯。

**章末钩子：**原定拦截通道之外，出现一支被火力困住的撤离车队。

### 第009章 防区之外

**视角与场景：**岳沉渊，前沿能源分配站与居民通道交界。

**目标与阻力：**他要保证洛弦节点组和供能站不被敌火力击穿。需要保护的地方比可标定防区更大，临时锚点也不足以承接全部冲击。

**场景拆解：**

1. 岳沉渊将重剑与分配站锚点相连，借「承界」导走穿过城市护盾的部分攻击。工程队在每次放电后调整冷却，守军拦截低空目标，读者看到保护的系统基础。
2. 旁侧居民通道受到威胁，地方军官请他扩大边界。他先答应再向调度报告，把原本可独立守住的站区与人群通道纳入同一负载，临时设施开始超过安全余量。
3. 工程人员提出接入备用锚点，必须暂时缩小防区。岳沉渊担心缺口里的人会受伤，推迟切换，迫使守军多派一组人穿过危险地段保护维修人员。
4. 洛弦收到过热数据，试图在总图上重新平衡力量，仍把他的“还能守”当作可靠输入。两人的决定没有立即导致失败，却共同减少了处理下一次变化的余地。

**人物推进与伏笔：**岳沉渊愿意承伤的优点带出负载与他人风险。提前建立第四卷轮换问题，但本卷只留下需要维护的装具与暂时疲劳。

**章末钩子：**供能站发出降载请求，前方却传来凌烬准备离位的消息。

### 第010章 没有按线走的人

**视角与场景：**洛弦，节点指挥车与疏散线路。

**目标与阻力：**她要在路线变化和局部供能下降时维持整张战术图。节点组能执行命令，现场信息却始终比图上的变化更快。

**场景拆解：**

1. 医院车辆与居民避开炮火，进入此前没有列入主疏散线的路段。洛弦计算新路径，要求多个岗位等待统一调整；现场军官提醒原有出口正在关闭，等待本身也会消耗时间。
2. 一组界钉运不到预定位置，她以更复杂的远程命令补偿缺口，尚未主动把决定权交给操作员。她确实保住了一段路线，也使更多反馈必须经过自己的判断。
3. 岳沉渊防区扩张导致供能变化，凌烬又报告车队求救。洛弦说明离位会让重装突破单位通过，他却认为可以赶在敌人抵达前救完人，两人对“来得及”的判断无法统一。
4. 敌方侦察察觉节点密度变化，把侧翼火力转向薄弱处。洛弦同时处理人群、供能和攻击，不肯放弃任何一个精确控制目标，操控负担逼近现场可用极限。

**人物推进与伏笔：**她的失败倾向来自过度集中判断，不是关心伤亡太少。具体落位问题为第二卷宁澈的专业价值预留位置，但宁澈此时不登场。

**章末钩子：**凌烬的定位信号离开了原定拦截区。

### 第011章 岔路口的呼救

**视角与场景：**凌烬，侧翼被困车队。

**目标与阻力：**他要打开车队的逃生通道，仍相信自己能及时返回岗位。真实救援比远处看到的复杂，敌人的推进也不会等他结束。

**场景拆解：**

1. 凌烬向指挥链报告后仍先行离位，认为救出前排车辆就能恢复交通。车队里有伤员和失去动力的车辆，平民不是配合战术的诱饵，他面对的是确实存在的生命危险。
2. 他切开堵塞结构，守军在旁侧提供短暂压制。第一辆车成功通过，随后地下管线与车辆重量使路面继续塌陷；救援需要工兵判断，无法用第二次挥剑直接结束。
3. 求救声使他想起过去没有赶到的那一次，他选择再向车队深处推进。原拦截区的部队报告敌重装单位已经换路，凌烬只能听见身后另一处防线请求增援。
4. 车队最终获得部分撤离空间，等待他的却不是预想中的空路。敌火力封住回程，工程人员继续抢救剩余车辆，他第一次看到亲自救一处人会使另一处人承担额外危险。

**人物推进与伏笔：**清楚写出善意、未经协调的选择与后果，不能把责任转为“车队是假目标”来替他开脱。此时只产生裂缝，尚未完成交托他人的成长。

**章末钩子：**原阵地传来一声急报：突破单位已经进入节点防线。

### 第012章 多出来的一段防线

**视角与场景：**岳沉渊，能源分配站外缘。

**目标与阻力：**他要补上凌烬离位后出现的突破缺口，同时保住原有保护区。设备余量已被先前扩张消耗，继续承接会把所有防护连成一个脆弱整体。

**场景拆解：**

1. 岳沉渊在短时间内改变部分攻击路径，为前沿守军争取重新架炮的机会。他没有能力隔空消灭突破单位，只能阻挡已经进入可标定区域的火力，敌人继续压近节点。
2. 工程人员要求先断开居民通道与主阵地的共用接口，地方部队负责转移人群。他担心交接瞬间失守，又延长了承接时间，过热设备开始影响主防区的稳定。
3. 洛弦需要几个节点维持敌方限制，岳沉渊把仅有的余量送过去。一个负责搬运冷却器件的普通班组不得不离开掩体，伤亡由具体动作产生，不作为衬托英雄强大的背景数字。
4. 最后一次承接暂时挡住火力，随后锚点出现结构裂缝。他明确报告不能再扩大，可敌人已经越过原定边界，军队只能边掩护边撤回星井外环。

**人物推进与伏笔：**“全部由我承担”的信念被现实反驳，读者看见维修人员与守军也在支付代价。临时损耗延续到下一次行动的维护，不写成永久右臂损伤。

**章末钩子：**一处关键界钉的供能灯熄灭，洛弦失去了前沿的完整视野。

### 第013章 破掉的节点

**视角与场景：**洛弦，遭突破的城市剑域。

**目标与阻力：**她要在节点被集中攻击后组织撤退，保住星井外环。继续追求原方案的完整控制，只会消耗最后的供能与撤离时间。

**场景拆解：**

1. 敌人先破坏供能和链路，再投入能穿过网隙的部队。洛弦发现多数失效不是自己操作慢了一步，而是有些物理节点已经不存在，不能用意志重新连接。
2. 她仍尝试逐个下达替代命令，指挥车收到多个互相矛盾的现场反馈。一个守军岗位自行转移伤员，使本可撤走的人活下来，也使她必须接受图上的状态不再由自己决定。
3. 韩策命令退至外环，明确舍弃已经无法守住的外围阵地。凌烬从车队回撤，岳沉渊缩小防区，常规部队以剩余火力和工事完成接应，三人才能脱离被分割的区域。
4. 退下后她先检查每一处失效记录，终于看到三人的选择怎样相互放大。她无法把这次失败解释为同伴不服从，也尚未愿意承认集中指挥本身存在局限。

**人物推进与伏笔：**首次协作正式失败，外围阵地丢失但星井仍在人类手中。地方自主行动保住伤员，为第五卷的分布式规则埋下可回看实例。

**章末钩子：**外环入口关闭，韩策要求三人先参加伤亡通报，再讨论下一次出击。

### 第014章 失败不是一个人的

**视角与场景：**韩策与凌烬，外环战后复盘。

**目标与阻力：**指挥部需要在下一轮登陆前重建协作。三人都能指出别人造成的缺口，却不容易承认自己愿意负责的做法也会害人。

**场景拆解：**

1. 通报先确认失去的阵地、未归队人员和还能使用的设施。凌烬见到自己第一场突破时合作过的岗位名录，发现一次出色的击杀并没有保证这些人活到撤退。
2. 韩策按时间顺序还原离位、扩区、集中补偿和节点破坏。每个决定都有救人的理由，组合后却让普通部队承担了无法解释的额外风险，三人不能靠争论谁更关心生命结束复盘。
3. 凌烬想立刻反攻，岳沉渊表示还能够承接，洛弦开始制定更密的命令。韩策逐一拒绝，要求他们先说明岗位、设备上限和通信失败后的动作，再谈胜利。
4. 他直言，再各打各的，地球最强的三个人会一起死在这里。许知微带来登陆舰一次实测供能切换，给出一种需要三人各自守住位置才能成立的新办法。

**人物推进与伏笔：**三人只接受一次有限的合作条件，不提前完成全部成长。复盘保留可追责的记录，避免往后的调查像临时新增的制度。

**章末钩子：**新方案中，凌烬必须等待一个他无法自行创造的窗口。

### 第015章 舰体换气的时候

**视角与场景：**许知微，工程分析室与登陆记录。

**目标与阻力：**她要证明登陆舰何时暴露可切断的连接。现有资料不完整，误把一个外露构件当作核心，可能让突击者再也无法返回。

**场景拆解：**

1. 工程队比对多轮登陆影像、护盾变化与缴获的局部部件，排除看起来最薄却没有承力意义的位置。许知微反复说明，外观弱点和真正能使舰体失效的连接并非同一件事。
2. 她确认重装部队投放时，护盾与主供能存在可预测切换，动力连接段会短暂暴露。窗口仍需守军诱导敌人按同样方式投放，不能只等待对手配合。
3. 洛弦计算局部封锁需要十三秒，能够可靠维持的攻击窗口只有七秒。岳沉渊按实测损耗给出这次可用承载，凌烬要求把抵达路径和失手后的撤出动作写清。
4. 指挥部确认一次试验和观测的必要性，留出军队压制、工程抢修与疏散岗位。许知微不承诺必胜，只签下已经被资料支持的结构判断。

**人物推进与伏笔：**首次让“哪里能切”的证据成为战斗主轴，第六卷将扩大这一方法而非突然新增能力。十三秒与七秒来自设备条件，不是随意报出的热血数字。

**章末钩子：**敌方新一轮重装投放开始准备，人类只有一次让它进入预定区域的机会。

### 第016章 没有人的坠落区

**视角与场景：**韩策为主，天京外环与预定废弃货运缓冲区。

**目标与阻力：**军队要诱导登陆舰进入可摧毁的位置，同时确保失去动力后的舰体不会压向平民。该方案对疏散、火力和场地确认的要求同样严格。

**场景拆解：**

1. 交通与守军两次核对缓冲区内人员，移走伤员、维修班组和仍可使用的储能设备。一个迟到车组让行动险些提前暴露，指挥员选择延后诱敌而非把人留在可能坠落的区域。
2. 常规部队在已经清空的阵地上制造可判断的撤退迹象，保留能逼迫敌人采用重装投放的火力。平民撤离是真实任务，不被安排成吸引舰艇的诱饵。
3. 工程队把导向防御场与卸载系统接入既有设施，只负责舰体失能后的有限偏转和承接。许知微明确，它们无法托住一艘正常作战的敌舰，计划必须先切断动力。
4. 三人分别确认出手位置、节点顺序与守护边界。凌烬听见别处求救，主动请求韩策指派支援，看见其他队伍接单后才继续准备，完成一次尚不稳固的岗位选择。

**人物推进与伏笔：**战术希望建立在普通岗位的准确执行上；凌烬第一次尝试让他人救援，但内心仍焦躁。坠落区的清点为后续胜利的可信代价提供基础。

**章末钩子：**登陆舰降低高度，洛弦开始十三秒封锁计时。

### 第017章 十三秒

**视角与场景：**洛弦为主，局部节点阵位；交错岳沉渊与守军。

**目标与阻力：**她必须在十三秒内完成封锁，且不再把所有细小变化都纳入自己控制。敌火力和受损接口会直接威胁这段准备时间。

**场景拆解：**

1. 计时启动时，洛弦报告：“十三秒后开窗。窗口只有七秒。”岳沉渊回应“十三秒，我守”，凌烬答“七秒，够了”。前五秒，操作员依次接通实体界钉，守军攻击敌投放前的掩护单位；洛弦只确认必须同步的节点，把预设的局部动作交给现场岗位。
2. 中段一处接口出现故障，岳沉渊按既定边界维持节点保护，工程人员替换连接。他看到防区外的爆点，没有擅自扩张，要求附近守军处理那里的危险。
3. 最后三秒，敌炮火打穿外层防护，岳沉渊把余波引向仍可用的卸载区。普通守军付出伤亡，凌烬看见自己能到达的一处伤员位置，仍留在准备好的突破通路上。
4. 最后一个节点确认接入，洛弦报告封锁完成，七秒窗口开启。岳沉渊守住回程支点，凌烬按约定出发；守军继续压制近防，把十三秒内各岗位的付出接成实际突破通路。

**人物推进与伏笔：**三人各让出一部分执念，交换可以相信的有限承诺；这只支撑一次短暂配合，并未解决后续规模化战争的难题。

**章末钩子：**封锁完成，登陆舰动力连接段进入七秒暴露窗口。

### 第018章 七秒够了

**视角与场景：**凌烬，登陆舰的近场突破通道。

**目标与阻力：**他要在封锁失效前切断主能源脊柱连接。路线、压制与结构信息已经具备，任何临时追击都可能错过唯一机会。

**场景拆解：**

1. 凌烬从预先接近的位置沿已打开的通道突入，守军与节点组压制近防，他不凭一跳从地面飞到高空。第一次接触验证许知微提供的供能变化，确认眼前连接确是目标。
2. 敌方护盾开始重建，连接外层承力结构试图替换受击点。他使用先前交锋得出的角度和反馈，沿可预测位置压缩有限储能，而非一眼看穿完整陌生舰体。
3. 剑线切断主能源脊柱，失去动力的舰体仍有巨大惯性。洛弦撤出封锁，岳沉渊守住回程节点，防御场与地面火力共同把舰体引向已疏散的无人缓冲区。
4. 凌烬沿预设路径撤回，残余部队接走受伤人员。舰体折断并坠落，明亮的剑线与沉重落地声形成第一次斩舰名场面，读者同时知道成功需要哪几个具体条件。

**人物推进与伏笔：**完成初次「锁—守—斩」，但公众将在第二卷逐渐把这次结果归结为三人的传奇。剑与身体的消耗需要检查和补充，不在镜头结束后自动清零。

**章末钩子：**天京欢呼时，地下维护记录出现一次此前未见的微弱响应。

### 第019章 胜利后的名单

**视角与场景：**凌烬与岳沉渊，外环救护区及废弃货运区。

**目标与阻力：**战场需要转入搜救与重建，三人却很难接受胜利无法抵消已经发生的死亡。残余敌军还在争抢舰体资料。

**场景拆解：**

1. 守军清点前沿与坠落区，确认事先疏散的作用，同时报告外围城区被毁和未能撤出的居民。三人面对真实名录，不让一场斩舰把失败与伤亡覆盖成漂亮战报。
2. 凌烬看到有人感谢自己，又听到另一户家属仍在询问失联者。他帮助核对路线和寻找记录，没有用“已经尽力”强迫对方接受，也不能把每一处搜救都亲自接走。
3. 岳沉渊拆下过热护具，第一次发现维修班组在自己坚持的那段防线付出了额外伤亡。他仍说不出应该什么时候交接，先把损耗与人员风险真实写进报告。
4. 敌回收队趁残局夺走部分地下测绘数据，守军阻击却未能追回全部。许知微保存三人同时全力接入时的异常记录，只说需要排除设备故障，不能提前解释星核来历。

**人物推进与伏笔：**把战果、责任与未知并列保存。数据被取走和星井异常响应成为第一篇的两条长期线索，留给第二、四卷逐步解释。

**章末钩子：**韩策通知三人，联合机构将给这次协作一个正式编号。

### 第020章 三极

**视角与场景：**韩策与三人，临时联合指挥所；尾段切赫因。

**目标与阻力：**人类要将一次偶然成功组织成可以持续执行的联合任务。三人接受共同编制，不代表纪律、后勤与相互信任已经成熟。

**场景拆解：**

1. 联合机构授予正式单位编号「三极」，韩策同时列出维护、训练、补给与任务汇报制度。授予不是庆功封神，而是要求三人的力量进入完整战争体系。
2. 凌烬要求保留对现场救援的判断，洛弦要求明确信息传递，岳沉渊关心保护边界。三人约定先报告、确认任务，再调整位置，这份初步规则在后续规模扩大时仍会被考验。
3. 天京恢复部分供能，伤员与居民进入长期安置。许知微向韩策提交异常记录，建议继续观测而非对公众宣布星核发生神迹；关于有限自治的争论也没有随着胜利消失。
4. 赫因复盘登陆舰损失，承认常规速胜成本过高，要求持续侦察星井结构与三人的能力边界。他决定准备长期补给和封锁，尚未在此刻完成外缘中继门或发动十二井总攻。

**人物推进与伏笔：**三人由各自行动走向有限组织化，九座以上未登场的星井仍有真实守军。敌人保留学习和改变战术的能力，第二卷的拉锯因此有明确起因。

**章末钩子：**三极收到第一项联合出城任务：护送封锁开始后仍必须送达的补给。

## 本卷写作检查

- 天京保住，十二座星井仍归人类；不要把外围阵地失守写成星井失守。
- 韩策、许知微正式登场；宁澈、伊瑟留到第二卷，闻岚留到第三卷。
- 星核异常只以原始观测出现；地下资料被抢走不等于人类已知抽核和种子。
- 首次斩舰的窗口由情报、诱敌、实体节点、守军压制和疏散共同创造。
- 三位主角只是做出一次有限修正，第二卷的过度自信与第三卷的失败仍有成立空间。
